# Simulador de Semaforos con Dijkstra

Pagina HTML autonoma para mostrar una simulacion de control de semaforos con prioridad calculada por Dijkstra.

## Abrir localmente

Abre `index.html` o `grafo2_para_compartir.html` con un navegador moderno.

## Publicar con GitHub Pages

Cuando el repositorio este en GitHub, activa Pages desde `Settings > Pages` y selecciona la rama `main` desde la raiz del repositorio.
